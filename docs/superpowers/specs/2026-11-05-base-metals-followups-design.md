## 2. 设计

### 2.1 库存历史累积（通用机制）

- 新增 `accumulate: true` 字段：抓取后把新观测并入 `data/accumulated/<scope>_<indicator>.json`，图表读合并后的完整序列；源头修订时以新值为准，并记录修订日期。
- 该文件随方案 C 的 `data` 分支持久保存；`data_branch.sh` 要把 `data/accumulated/` 子目录纳入同步（现在只同步 `data/*.json`，需要改）。
- 先用于上期所铜、铝、锌、镍库存。以后其他短窗口来源也可以用。

### 2.2 上期所近远月价差

- 每个交易日取未到期合约中最近的两个活跃月，以及第三个月；价差 = 近月 − 第三月（元/吨），正值表示 backwardation。
- 换月规则：合约进入交割月前最后一个交易日换到下一个合约，写进 caveat。
- 先做铜，结构稳定后加铝。数据等级 `public_wrapper`（新浪经 AKShare）。

### 2.3 秘鲁铜产量

- fetcher 读 gob.pe 上 MINEM 的出版物列表，找到最新一期的 Excel 附件，解析铜产量表；历史按每月一期逐步累积（复用 2.1）。
- 风险：列表页或表格版式一变就失效。失效时页面显示「过期」，不显示错误数值；解析器用版式断言而不是位置猜测。

### 2.4 COMEX 金银库存（贵金属页，顺带）

- `futures_comex_inventory` 的黄金、白银两条，日度，`public_wrapper`。

### 2.5 中国精炼铜产量与进出口——先探查

- 用半天时间在东方财富行业指标里找精炼铜产量、铜矿砂及精矿进口、未锻轧铜及铜材进出口；能找到就接，找不到就记为 gap。不猜代码。

## 3. 非目标

- 不接授权数据（LME、CME 官方库存、Platts/Argus）。
- 不做供需平衡表或预测。
