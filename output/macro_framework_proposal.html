Framework Design Principles

Guiding philosophy: The current 7-section structure (Real → Prices → External → Fiscal → Monetary → Markets) follows the classic IMF Financial Programming Framework (FPP) flow. This proposal deepens each existing section and adds sections for Financial Stability, Demographics, and Political Economy — domains that are structural drivers for CEE assets but currently absent. All proposed indicators are available from free, machine-accessible sources (Eurostat API, ECB SDW, BIS API, national central bank statistical portals). No Bloomberg/Reuters terminal required.

§7 Financial Stability & Banking

NEW · 金融稳定

§8 Demographics & Labour Supply

NEW · 人口结构
Rationale: Demographics are the slowest-moving but most powerful structural variable. CEE-4 faces acute demographic headwinds (negative natural growth, net emigration, aging). These drive potential GDP, fiscal sustainability (pension systems), and the NAIRU. For CEE, the interaction of demographics + EU labour mobility is a macro variable as important as the policy rate.

Implementation Roadmap

Phase 1 — P1 Indicators (Quick Wins, ~2 weeks)

Add all Priority 1 indicators across all sections. These are available via Eurostat API, ECB SDW, and BIS — all have REST APIs and existing Python wrappers. Estimated 42 new indicators (~60 charts). Data can be pulled via the openecon-data MCP or direct API calls.

Phase 2 — P2 Indicators (Deepening, ~2-3 weeks)

Add Priority 2 indicators. Some require national central bank statistical portals (fragmented access, may need per-country scrapers). Market data (CDS, inflation swaps) may require Bloomberg/Refinitiv access or free alternatives (investing.com scrape with caution).

Phase 3 — P3 & New Sections (Professionalisation, ~3-4 weeks)

Add Financial Stability (§7), Demographics (§8), and Political Economy (§9) sections. Build narrative templates for each. Standardise chart styling and add peer comparison for all indicators.

Data Pipeline Architecture

Suggested: a data_fetcher.py module with per-source adapters (EurostatFetcher, ECBFetcher, BISFetcher, NationalCBFetcher) that output a canonical DataFrame with columns [country, date, indicator_id, value]. The base HTML generator consumes this DataFrame. This decouples data acquisition from chart generation and makes indicator addition a configuration change, not a code change.
