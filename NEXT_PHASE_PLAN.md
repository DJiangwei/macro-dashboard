## 3. Brainstorming: How To Think About Remaining Proxies

The remaining proxy list is not one uniform problem. It splits into five different classes, each requiring a different strategy.

### Class A: Official Statistical Data, Likely Replaceable

These should be the next highest-priority targets because they can probably be replaced by Eurostat, ECB, BIS, IMF, World Bank, national central banks, or national debt offices.

Targets:

- `gas_storage_level`
- `foreign_ownership_bonds`
- `fx_loan_share`
- `avg_debt_maturity` for Hungary
- `short_term_ext_debt` for Czechia if IMF ARA coverage remains missing or mismatched
- `foreign_bank_share` for Romania
- `import_prices_yoy`

Likely source families:

- ECB Balance of Payments and International Investment Position datasets.
- Eurostat government debt structure datasets.
- BIS locational/consolidated banking/debt securities datasets.
- National central bank statistical portals.
- National debt office or ministry of finance debt reports.
- GIE AGSI or energy storage APIs for gas storage, if access is available.

Recommended posture:

- Replace these before touching vendor-like market indicators.
- Prefer imperfect but official annual data over plausible-looking synthetic monthly proxies.
- If a source is stale but official, show it as `watch`, not `verified`.

### Class B: Market Vendor Data, Hard To Replace Cleanly

These usually require Bloomberg, Refinitiv, FactSet, S&P, MSCI, JP Morgan, or local exchange/vendor access.

Targets:

- `cds_5y`
- `embi_spread`
- `breakeven_5y5y`
- `fx_implied_vol`
- `fx_3m_forward`
- `equity_fwd_pe`
- `equity_pb`
- `equity_div_yield`
- `equity_vol_30d`
- `carry_trade_return`

Possible open substitutes:

- Use exchange-published equity index levels where Yahoo fails.
- Use sovereign spread vs Bund as an open proxy for EMBI-like sovereign risk.
- Use ECB or Eurostat long-term rates where 2Y or curve data exists.
- Use FX spot plus interest-rate differential as a carry-only proxy, but keep a clear label.
- Use listed ETF or index-provider pages only if terms and stability are acceptable.

Recommended posture:

- Do not over-optimize these until official-data indicators are mostly solved.
- Keep transparent proxy or `low_confidence` badges if the data is not a true market-vendor equivalent.
- If using public market feeds, make the source label honest: `public proxy`, `vendor feed`, or `derived open-data proxy`.

### Class C: Policy/Event-Driven Data, Better As Curated Manual Series

These are not naturally time-series API problems. They are event/state trackers.

Targets:

- `eu_funds_absorption`
- `eu_funds_frozen`
- `cb_forward_guidance`

Likely source families:

- European Commission country pages and EDP documents.
- European Council/Council of the EU procedure pages.
- Rating agency press releases and sovereign rating calendars.
- National budget documents.
- Central bank meeting statements and minutes.

Recommended posture:

- Create a structured manual data layer rather than pretending these are API indicators.
- Store observations, source URLs, dates, and notes in YAML.
- Render them with distinct UI copy: `curated policy tracker`, not `statistical series`.
- Add a reminder field such as `review_after` or `next_event_date`.

### Class D: Survey / Leading Indicator Data With Coverage Problems

These may be public, semi-public, or country-incomplete.

Targets:

- `manufacturing_pmi`
- `oecd_cli`
- `ifo_expectations`
- `truck_km_index`

Findings so far:

- OECD CLI public SDMX coverage did not include the CEE-4 countries in the tested query.
- PMI is usually S&P/HCOB/vendor-controlled and may not have stable free historical APIs.
- Ifo expectations are more naturally Germany/Eurozone spillover indicators, not domestic CEE indicators.
- Truck-km indicators may come from toll operators, logistics platforms, or national road agencies, often country-specific.

Recommended posture:

- Decide whether these belong in the core dashboard or in an optional `alternative / nowcast` subsection.
- If kept, label them as spillover or alternative indicators, not official macro statistics.
- Consider replacing `ifo_expectations` with Germany Ifo as an external-demand proxy, especially for Hungary/Czechia/Poland.

### Class E: Already Useful As Proxy, But Needs Better UI Treatment

Some indicators may stay proxied for a while. That is acceptable if the UI makes the limitation elegant and visible.

Targets:

- Vendor valuation metrics.
- Market-implied metrics.
- Qualitative central-bank guidance.

Recommended UI treatment:

- Use a small top-right badge: `proxy`, `manual`, `vendor`, `lagged`, `official`.
- Add hover tooltip for quality notes.
- In the data quality panel, group indicators by reason: `official`, `derived`, `manual`, `proxy`.
- Do not let proxy charts visually look identical to verified official charts.

## 4. Proposed Next Implementation Phases

### Phase 1: Source Matrix And Quick Official-Data Wins

Goal:

Reduce the remaining proxy count by replacing the most plausible official-data gaps first.

Concrete tasks:

1. Add a `SOURCE_DISCOVERY_MATRIX.md` or YAML equivalent that maps every remaining proxy to candidate sources, status, and next action.
2. Investigate national debt-office data for Hungary `avg_debt_maturity`.
3. Investigate national central bank or ECB data for `fx_loan_share`.
4. Investigate national debt management sources for `foreign_ownership_bonds`.
5. Investigate GIE AGSI or national energy storage pages for `gas_storage_level`.
6. Re-test `import_prices_yoy` across Eurostat and national-stat sources.
8. Validate each candidate with four checks: country coverage, latest date, unit/frequency, and whether it matches the indicator label.

Definition of done:

- At least 3 additional indicators are replaced with official or clearly labeled derived sources.
- Each new adapter has a source URL, series ID, quality note, and validation status.
- Generated country pages show the new source names in footnotes.
- Pages are pushed and confirmed live.

### Phase 2: Manual Curated Policy Layer

Goal:

Move qualitative and event-driven indicators out of generic proxy generation into an explicit curated data workflow.

Concrete tasks:

1. Extend `config/manual_indicators.yaml` beyond `eu_funds_frozen`.
2. Add manual entries for `sovereign_rating`, `edp_status`, `eu_funds_absorption`, `contingent_liabilities`, and `cb_forward_guidance`.
3. Add fields:

```yaml
source:
unit:
quality_status:
quality_note:
review_after:
references:
observations:
```

4. Create a small validator that checks manual observations have valid dates, numeric values, and references.
5. Update UI copy so manual policy indicators are styled as `manual research series`.

Definition of done:

- Event-driven policy indicators no longer use generic proxy fills.
- Manual indicators show clear source references and review dates.
- The dashboard user can distinguish official data from curated judgments.

### Phase 3: National Data Fetcher Layer

Goal:

Create country-specific adapters for CEE-4 data that global APIs do not cover.

Concrete tasks:

1. Split national-source logic into a clearer class or module, for example:

```text

  hungary.py
  poland.py
  czechia.py
  romania.py
```

2. Target initial national-source indicators:

```text

foreign_ownership_bonds
fx_loan_share
gas_storage_level

foreign_bank_share for Romania
```

3. Standardize output into the existing canonical rows:

```text
country, date, indicator_id, value, source, series_id, quality_status, quality_note, is_proxy
```

4. Add per-country source notes because national methodologies will differ.

Definition of done:

- National-source data does not contaminate global fetchers.
- Every country-specific exception is traceable and easy to maintain.
- Missing coverage degrades gracefully to proxy/manual data.

### Phase 4: Market Data Strategy

Goal:

Decide what should remain proxy versus what can be replaced with public market-data alternatives.

Concrete tasks:

1. Fix Czechia and Romania equity index coverage if an exchange or stable public endpoint can be found.
2. Derive `equity_yoy` and `equity_vol_30d` from those index levels after the index feed is fixed.
3. Reassess whether `equity_fwd_pe`, `equity_pb`, and `equity_div_yield` should remain in the dashboard without a vendor.
4. Consider replacing valuation metrics with more open indicators:

```text

equity_yoy
equity_vol_30d
sov_spread_vs_bund
real_policy_rate
credit_to_gdp_gap
```

5. Keep CDS, EMBI, breakeven, and FX vol as transparent proxies unless a robust public source exists.

Definition of done:

- Public market-data proxies are honest and clearly labeled.
- Vendor-only indicators are either removed, hidden behind `requires vendor`, or retained as `low_confidence proxy`.

### Phase 5: UI And Quality System Upgrade

Goal:

Make data quality more legible and aesthetically aligned with the East Meridian editorial style.

Concrete tasks:

1. Add quality categories:

```text

manual

```

2. Replace generic `watch` with more informative badges where possible.
3. Add a compact data-quality legend at the top of each country page.
4. Add hover or expandable footnotes for long quality notes.
5. In the section index, show how many charts are official vs proxy.
6. Consider sorting or filtering charts by quality status in future versions.

Definition of done:

- A user can immediately tell which indicators are robust versus directional.
- Proxy charts feel intentionally disclosed, not like bugs.

## 8. Operating Rules For Future Work

1. Never silently replace a proxy with a source whose definition does not match the chart title.
2. If the source is official but stale, use `watch`, not `verified`.
3. If the source is vendor-like or scraped, say so in the footnote.
4. If a value is manual/curated, label it as manual and include references.
5. Always rebuild all four pages after data-pipeline changes.
6. Always validate before commit.
7. Always push and wait for GitHub Pages to build before calling the update complete.
8. Always smoke test the live URL with a cache-busting query parameter.
9. Keep the generated HTML in sync with source changes.
10. When in doubt, preserve a transparent proxy rather than showing a misleading official-looking chart.
